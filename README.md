# 数据结构基础课程代码仓库

本仓库为本人在大学《数据结构基础》课程学习过程中的代码、作业、项目与实验报告的集中记录，旨在系统梳理和实践数据结构与算法的核心知识点。

---

## 📚 课程简介

《数据结构基础》是计算机相关专业的核心课程，主要内容涵盖：

- 线性表、栈、队列、串、数组、广义表等基本数据结构
- 树、二叉树、图等非线性结构
- 各类查找与排序算法（如顺序查找、二分查找、冒泡排序、快速排序等）
- 算法复杂度分析与递归思想
- C语言实现与算法工程化实践

---

## 🗂️ 目录结构说明

- `HW*`：各次课后作业的 C 语言源代码文件
- `project1/`、`project2/`：课程设计/大作业的完整项目代码、头文件、CMake 配置及实验报告
- `assets/`：课程相关的图片、素材等资源
- `README.md`：本说明文档
- 其他：如 `report.md`、`test.md` 等为实验或测试文档

---

## 🚩 项目亮点

- 代码风格规范，注释详细，便于理解和复用
- 递归与非递归算法实现对比，帮助理解算法思想
- 项目采用 CMake 管理，支持跨平台编译
- 每个项目/作业均配有实验报告，便于总结与复盘
