# FDS

数据结构基础（FDS）课程的个人代码库，存放作业、项目和实验代码。

## 目录

- `HW*` / `HW*.c` — 课后作业，涵盖排序、查找、图、树等经典算法
- `project1/` `project2/` `project3/` — 课程项目，CMake 管理，含实验报告
- `assets/` — 图片等资源

## 内容

代码以 C 实现，主要包括：

- 排序：冒泡、选择、插入、快速、归并、堆排序
- 查找：顺序查找、二分查找
- 线性结构：链表、栈、队列
- 树与图：遍历、连通分量等

作业和项目写了比较详细的注释，回头看能快速理解思路。

## 技术

C + CMake，VS Code / Linux 下开发。
